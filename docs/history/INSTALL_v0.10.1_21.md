# Install Potion Post v0.10.1 (Build 21)

Install potion-post-v0.10.1-build21.apk as an Update to Potion Post Ads Test. The application ID remains com.castilla.potion_post.adtest and the existing signing key is retained. Keeping the installed app preserves its private local save.

Open Settings and check v0.10.1 (21). Screens preload their required artwork before revealing it, with a short fade and gentle entrance movement. Neighboring gardens and common destinations warm in the background. Portraits and garden thumbnails decode at a smaller working size, while tablet backgrounds retain up to their original 1024-pixel width. On a cold launch, a lightweight native postal loading panel stays visible until the first scene is ready. Both the app and Android Reduce Motion preferences suppress transition movement.

The artwork, 1,480 orders, 43 routes, 26 courier identities, saves, rewards, Coins and purchases are retained. Google demonstration ad IDs remain active. Real-money coin packs are unavailable in this test edition. The single persistent test-ad banner remains below the game Navigator.

For a source build use the pinned toolchain in README.md, then run flutter pub get, flutter analyze, flutter test and flutter build apk --release --flavor adtest.
