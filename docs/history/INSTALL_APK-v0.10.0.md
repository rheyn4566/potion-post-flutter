# Install Potion Post v0.10.0 (Build 20)

Install potion-post-v0.10.0-build20.apk as an Update to Potion Post Ads Test. The application ID remains com.castilla.potion_post.adtest and the existing signing key is retained. Keeping the installed app preserves its private local save.

Open Settings and check v0.10.0 (20). The update includes full garden environments, smaller grounded inhabitants, shared scenery/character projection, plain native controls without decorative flower clusters, a clear gameplay courier card and a quieter Friends collection display. The current five tabs, progress and purchases remain interactive.

Google demonstration ad IDs remain active. Real-money coin packs are unavailable in this test edition. The persistent test-ad banner remains below the game Navigator.

For a source build use the pinned toolchain described in README.md, then run flutter pub get, flutter test, flutter analyze and flutter build apk --release --flavor adtest.
