# Install Potion Post v0.11.0 (Build 22)

Install potion-post-v0.11.0-build22.apk as an Update to the existing Potion Post Ads Test installation. The launcher name becomes Potion Post. The package ID and signing key are unchanged, so keep the installed app and its private save. Settings should show Potion Post · v0.11.0 (22).

If the direct APK download fails, download potion-post-v0.11.0-install.zip, extract the APK and open it. The ZIP contains the exact same signed APK; no conversion or separate installer is needed.

This build adds larger level controls, functional branded settings, a native delivery celebration, and the new Pip launcher icon. The single SDK banner appears only after the Google SDK loads an ad; there is no custom Advertisement/Test placeholder or permanent empty footer. Official demo ad IDs remain active until the publisher supplies their IDs. Any Test Ad marking inside the SDK creative belongs to Google.

The artwork, 1,480 story orders, 43 garden routes, 26 couriers, local progress, earned Coins, rewards and purchased companions/decorations are retained. Existing scene preloading and reduced-motion support remain enabled. The in-game coin shop offers earned rewards and game purchases; no cash-pack products are advertised.

Physical tablet performance and real-device ad loading need testing on your device. Publishing preparation is documented in docs/RELEASE_POLISH.md.
