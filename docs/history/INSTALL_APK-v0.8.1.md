# Install Potion Post v0.8.1 (Build 18)

Install potion-post-v0.8.1-build18.apk as an update to Potion Post Ads Test. The application ID is com.castilla.potion_post.adtest and the included existing test signing key is retained. Android should offer Update. Keeping the installed app preserves its private local save.

The app uses Google demonstration ad IDs. Coin packs for real money are not enabled. Earned Coins, purchases, partial puzzles and garden progress use the existing local save format.

Check Settings for v0.8.1 (18). This update corrects illustrated button and panel alignment on Android, restores the full Pause/Delivery dialog background, lines up all five navigation tabs and improves the Daily courier/counter framing on short screens. It retains 18 additional scene illustrations, 43 garden routes, 26 companions and 1,480 story orders.

For source builds: use Flutter 3.47.6 or a compatible stable SDK with Dart 3.11+, a JDK (not a JRE), Android SDK 36, and the included test-edition key. Run flutter pub get, flutter test, flutter analyze, then flutter build apk --release --flavor adtest.
