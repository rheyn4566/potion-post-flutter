# Bento UI refinement — 0.6.1

The reference images informed the compact game HUD, clear icon buttons and
small lower button rims. Potion Post retains its own garden art, couriers,
Poppins typography and potion-matching rules.

Home groups its actions into a larger Play tile, a Daily tile and a row of
three matching shortcuts. Settings and Help sit in compact rounded-square
controls beside the stamp counter. Labels, gaps and corner treatments follow
the same system across puzzle tools, level buttons and friend rewards.

Buttons use a matte face, a four-pixel lower rim and brief press travel.
Disabled controls cannot activate; system and in-game reduced-motion settings
remove animated travel. The existing bottle lift, flight and pouring remain.

The layout adapts into two columns in landscape. Home and active puzzles
remain fixed on screen; collections may scroll. All 1,000 orders, character
records, daily rules, reward thresholds and existing save data are unchanged.
